# B2B-F хавтангийн texture цуглуулга

2026-10-22-нд [B2B-F](https://b2b-f.mn/mn)-ийн нийтэд нээлттэй бүтээгдэхүүний хуудас болон тэдгээрт байрлуулсан татах холбоосоос цуглуулав.

Каталог: http://localhost:3000/materials/b2b-f/index.html

## Цуглуулсан материал

| Төрөл | Бүртгэл |
| --- | ---: |
| ДСП | 59 |
| MDF | 33 |
| Ламинат / Хуулга | 11 |
| Аргиллит | 15 |
| Арын хана | 29 |
| Ажлын тавцан | 21 |
| Компакт | 2 |

Зарим бүтээгдэхүүн хоёр ангилалд багтдаг. Бүтээгдэхүүний URL-аар давхардлыг арилгахад **166 бүртгэл** болсон. Нэг декор өөр төрлийн хавтан, гадаргуугаар тусдаа бүртгэлтэй байж болно.

- Нийт **293 зураг**: 166 бүтээгдэхүүний зураг, 119 дүрслэл/хэвлэлийн texture файл, 8 бусад лавлах зураг.
- **91 бүтээгдэхүүнд** texture файл байна; texture файлуудын SHA-256-аар ялгаатай **87 эх зураг** байна.
- **15 бүртгэлд** өөр декорын кодтой ижил texture файл холбогдсон. Эдгээрийг каталогт тэмдэглэж, бүтээгдэхүүний үндсэн зургийг үзүүлсэн; `candidateBaseColor` утгыг `null` болгосон. Энэ нь тухайн 15 бүтээгдэхүүн бүгд буруу гэсэн дүгнэлт биш, эх холбоосыг нягтлах шаардлага юм.
- Зураг татах 12 холбоос PDF файл заасан тул texture гэж оруулаагүй.
- Эх зургуудын хамгийн урт тал **7937 px** хүртэл байна.

## Байршил

- Өөрчлөлтгүй эх файлууд: `.research/b2b-f-library/images/`
- Эх файлын бүртгэл: `.research/b2b-f-library/manifest.json`
- Эх холбоосын зөрчлийн тайлан: `.research/b2b-f-library/source-audit.json`
- Вебэд зориулсан хувилбар: `public/materials/b2b-f/images/`
- Каталог: `public/materials/b2b-f/index.html`
- Веб материалын бүртгэл: `public/materials/b2b-f/manifest.json`
- Урьдчилсан харагдац: `public/materials/b2b-f/contact-sheet.jpg`

Бүртгэлд ашигласан эх зургууд нийт 1648.58 MiB, веб хувилбарууд 42.17 MiB. Веб зургуудыг урт тал нь 2048 px-ээс хэтрэхгүй, харьцааг нь хадгалсан WebP болгосон. Жижиг эх зургийг томруулаагүй. Эх архивт эхний таталтын жижиг preview зургууд мөн хадгалагдсан.

## 3D материалд хэрэглэхдээ

`supplier-design-download` нь нийлүүлэгчийн “Зурганд ашиглах” эсвэл “Хэвлэхэд тохиромжтой” холбоосоос авсан зураг; `catalog-swatch` нь бүтээгдэхүүний зураг. `supplier-reference-download` ангиллыг үндсэн өнгөний texture гэж сонгохгүй.

Normal, roughness, metalness map энэ цуглуулгад байхгүй. Хээний давталт, бодит миллиметрийн хэмжээ, зургийн чиглэлийг баталгаажуулаагүй тул seamless PBR багц гэж үзэхгүй. Бүртгэлд эдгээр утгыг таамгаар бөглөөгүй.

Цуглуулга нь сонгох, татах боломжтой тусдаа локал каталог. Planner-ийн идэвхтэй материалын өгөгдлийн сан руу автоматаар импортлоогүй.

## Шалгалт

293 зургийг Sharp-аар нээж, нягтрал болон файлын хэмжээг баталгаажуулсан. Каталогийн JavaScript syntax шалгалт давсан. Chrome дээр 166 бүртгэл, 15 зөрчлийн тэмдэглэгээ, H3303 кодын хайлт, compact ангиллын 2 бүтээгдэхүүн, texture шүүлтүүрийн 91 бүтээгдэхүүнийг шалгасан. Дэлгэцийн өргөнөөс хэтэрсэн хэвтээ гүйлгэлт байгаагүй.

## Дахин ажиллуулах

```powershell
node scripts/materials/collect-b2b-textures.mjs
node scripts/materials/build-b2b-gallery.mjs
```

Татах скрипт `research/b2b-f-category-seeds-2026-10-22.json` дахь нийтэд нээлттэй эх холбоосуудыг ашиглана. Категорийн жагсаалт нь 2026-10-22-ны байдлаарх зураглал тул шинэ бүтээгдэхүүнийг оруулахад эх жагсаалтыг шинэчилнэ. Нийтэд нээлттэй зураг татахад сүлжээ шаардлагатай; вэб дээр зурагтай холбоотой үнийн мэдээлэл цуглуулаагүй.
