# Kitchen Planner — боксын өнгө солих

2026-10-23

Сонгосон боксын их бие, фасадын өнгийг тус тусад нь өөрчлөх удирдлага нэмэв.

Хэрэглэх дараалал: **Бокс сонгох → Өөрчлөх → Боксын өнгө / Материал**.

- Их бие болон фасад тус бүр 8 бэлэн өнгө, дурын HEX өнгө, байгаа материалын сангийн сонголттой.
- Материалын сангаас сонговол тухайн материалын өнгө, roughness, metalness, texture хамт хэрэглэгдэнэ.
- Өөрчлөлт нь сонгосон бокс дээр хэрэгжинэ. Хэсэг тус бүрийг эсвэл боксыг бүхэлд нь эх материалд буцааж болно.
- Custom өнгө нь `frontMaterialId` / `carcassMaterialId` талбарт `paint_rrggbb` хэлбэрээр хадгалагдана. Өгөгдлийн сангийн шинэ материалын мөр шаардахгүй; хуучин загварын схем өөрчлөгдөөгүй.
- GLB-ийн нэрлэсэн эд ангиудыг ашиглана. Ерөнхий нэртэй хаалгыг хэлбэр, байрлалаар ялгаж, жижиг тоноглол болон нэрлэсэн шил, бариул, цахилгаан хэрэгслийг хэвээр үлдээнэ.
- Kitchen GLB-ийн хэсгүүдийг тус тусад нь будах боломжийг хадгалахын тулд эдгээрт автомат mesh instancing хэрэглэхгүй. Room Planner-ийн ердийн загваруудын instancing хэвээр.
- Assembly загварын frame, хаалга, шургуулгын нүүр болон их биеийн хэсгүүдэд мөн өнгө, материалын сонголтыг дамжуулсан.
- 2D / 3D шилжихэд камерын товчлууруудын CSS алдагдахгүйн тулд `viewport-controls.css`-ийг planner-ийн route layout дээр ачаалдаг болгосон.
