# IKEA албан ёсны эх сурвалжийн судалгаа

Судалсан өдөр: 2026-10-20. Энэ файл зөвхөн IKEA-ийн нийтэлсэн баримтад тулгуурлана; runtime REA ажиглалт биш. Улс, төхөөрөмж, хувилбараар боломж өөр байж болно.

## 1. Kreativ ба Kitchen Planner-ийг ялгах нь

Kreativ нь өрөөндөө IKEA тавилга, décor-ыг харах, хөдөлгөх, солих зориулалттай. IKEA өөрөө гал тогоо, угаалгын өрөөнд зориулалтын planner ашиглахыг зөвлөдөг. 2022 онд шинэчилсэн Kreativ catalog-ийн help-д kitchen cabinets, зарим тааз/ханын эдлэл, textile зэрэг байхгүй гэж тэмдэглэсэн; өнөөгийн бүх улсын catalog-д адил гэж шууд дүгнэж болохгүй.

- https://www.ikea.com/ca/en/customer-service/knowledge/articles/g81237dc-557d-4d2e-b0fd-24c6d8e46705.html
- https://support.home-design.ikea.com/hc/en-us/articles/360038999793-What-can-I-design-in-my-space

## 2. Өрөөг эхлүүлэх гурван зам

Одоогийн US getting-started баримт гурван үндсэн сонголттой: өөрийн зураг оруулах/авах ба хуучин тавилга арилгах; LiDAR-аар full-room scan хийх эсвэл веб дээр хэмжээс оруулан хоосон 3D room байгуулах; 50+ хоосон эсвэл тохижуулсан starter room-оос эхлэх. Full-room scan-ыг app дээр LiDAR-enabled төхөөрөмжөөр хийж, боловсруулалт дуусахад email ирдэг; ижил account-аар веб дээр үргэлжлүүлнэ.

## 3. Каталог, бодит хэмжээ, item action

Веб дээр item сонгоход Action Panel гарч rotate, flip, swap, duplicate, remove, Add to Bag, Favorites, Goes Well With үйлдлүүдийг өгнө. Swap replacement нь ижил байрлалд орно; left catalog дотор Swap with similar, Goes well with байдаг. Үйлдлийн жагсаалт product төрлөөс хамаардаг: хананд тогтдог эдлэлд ердийн rotate байхгүй байж болно.

- https://www.ikea.com/us/en/customer-service/knowledge/articles/947c11dc-0346-4cb6-ade0-ba6972b2d8bc.html

Бүтээгдэхүүнийг дур мэдэн сунгаж багтаадаггүй, бодит scale-аар байрлуулдаг. UK help нь manual builder-д хэмжээс эхэнд оруулах, дараа засах нь “coming soon” гэж тайлбарласан. Scan/photo-ийн хэмжээг best practices нөхцөлд ойролцоогоор 97% accurate гэж IKEA мэдээлсэн; энэ нь бие даасан хэмжилтийн баталгаа биш.

## 4. Save → хувилбар → share → худалдаа

Cloud/account хадгалалт, cart руу нэмэх, share хийхийг IKEA launch баримт тайлбарласан. Шинэ Finland help-д web Save a Copy, app Duplicate; web Remix link-ээр бусад хүн засах, app-аар image share хийхийг ялгасан. Энэ нь “байрлуул → харьцуулж турш → хуулбар хадгал → бүтээгдэхүүний жагсаалт/сагс” гэсэн урсгалыг батална.

## 5. AI яг хаана ашигласан нь баримттай вэ?

2022 launch нь Geomagical Labs-ийн technology-г нэрлэсэн: indoor objects/geometry таних neural network, stereo vision, computational photography, mixed-reality graphics, furniture erase. Зургуудыг боловсруулан editable replica гаргадаг гэж тайлбарладаг. Энэ баримт нь “AI бүх тавилгыг шинээр model хийдэг” эсвэл “AI автоматаар шилдэг 5 зохион байгуулалт гаргадаг” гэдгийг батлахгүй.

Энэ судалгаагаар IKEA furniture asset production-ийн яг CAD → retopology → texture baking → GLB pipeline, polygon budget, material packing, LOD, naming convention-ийг баталсан official нийтлэл олдоогүй. Үүнийг REA runtime evidence эсвэл engineering source-гүйгээр IKEA-ийн бодит implementation гэж бичиж болохгүй.

- https://www.ikea.com/us/en/newsroom/corporate-news/ikea-launches-new-ai-powered-digital-experience-empowering-customers-to-create-lifelike-room-designs-pub58c94890/

## 6. Гал тогооны planner-ийн албан ёсны ажлын урсгал

METOD help: account/login ба хэмжээсээ бэлдэх → oven position, hood, fridge/freezer, layout сонгох (эсвэл шууд room define) → ойролцоо room shape сонгох → хэмжээс оруулах → Customize хэсэгт cabinets/appliances/accessories нэмэх. Бэлэн kitchen solution-оос эхлээд тааруулж болно. Cabinet door grip байрлалаар opening direction өөрчилж, Open үйлдлээр хөдөлгөөнийг шалгана.

- https://www.ikea.com/de/en/customer-service/knowledge/articles/f4aa1b4f-d00d-4413-92ad-fa12de7d0977.html

IKEA-ийн нийт lifecycle: style → measure → plan/design → specialist review/delivery → installation. Planning guide нь захиалгаас өмнө plan validation санал болгодог.

## 7. Манай planner-д авах сургамж (дүгнэлт, IKEA implementation гэж батлаагүй)

1. Product family + бодит variant/SKU + хэмжээ + mount type + supported actions + asset reference гэсэн catalog data contract эхэлж тогтоох.
2. Floor/wall/ceiling mounting constraint-ыг material/color-оос тусад нь хадгалах; дээд шүүгээг base cabinet болгон fallback хийхийг хориглох.
3. Room setup → fixed openings/services → layout → cabinet arrangement → finish → opening/collision review → quote/save гэсэн шаттай урсгал.
4. Generative зурагнаас илүү зөв scale, чанартай product assets, swap-in-place, контекст action panel, copy/compare урсгал нь эхний ач холбогдолтой.
5. ML training-ийг scan/segmentation эсвэл personalization хэрэгцээ ба өгөгдөл бий болтол хойшлуулах; эхлээд constraint/rule engine, catalog чанар, rendering pipeline-ийг сайжруулах.
