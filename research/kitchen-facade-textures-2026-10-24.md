# Kitchen Planner — фасадын texture засвар

2026-10-24

## Олдсон шалтгаан

Татсан B2B-F / EGGER хээнүүд тусдаа локал каталогт байсан бөгөөд Planner-ийн материалын сонголтод холбогдоогүй байв. Одоогийн 1000 мм GLB-ийн их бие болон хаалганы mesh-үүд `POSITION`, `NORMAL` атрибуттай боловч `TEXCOORD_0` буюу UV мэдээлэлгүй байсан. Иймээс өнгө солигддог ч зураг хээ болж харагдахгүй байв.

## Засвар

- Эх холбоосын зөрчилгүй, зориулалтын texture файлтай **66 хээг** Planner-ийн материалын санд нэмсэн. Ижил нэр, ижил эх зурагтай давхардлыг нэгтгэсэн. Зөвхөн бүтээгдэхүүний зурагтай болон эх холбоосыг нягтлах шаардлагатай бүртгэлүүдийг оруулаагүй.
- Админы материалын тодорхойлолт давхардсан ID дээр давуу эрхтэй. Хуучин бэлэн өнгөнүүд хадгалагдсан. Одоогийн локал каталог их бие болон фасад тус бүр **70 сонголттой** харагдсан.
- `Өөрчлөх → Боксын өнгө / Материал → Фасад / Хаалга → Материалын сан` хэсгээс кодоор хайж сонгоно. Жишээ: **H3303**.
- Их биеийн олон материалын жагсаалт фасадын удирдлагыг доош түлхэхгүй байхаар жагсаалтыг эвхэгддэг, дотроо хайлт болон хязгаартай гүйлгэлттэй болгосон.
- UV-гүй, бүх цэг нь ижил UV-тэй эсвэл хүчингүй UV-тэй текстуртай mesh-д preview координат үүсгэнэ. Зургийн харьцааг хадгалж, боксын хавтгайд нэг удаа тааруулна. Залгаа хаалганы хээ зааг дээр үргэлжилнэ.
- Бэлэн зөв UV-тэй загваруудын UV болон эх GLB файлыг өөрчлөөгүй. Шинэ координат хэрэгтэй mesh-ийн geometry-г clone хийсэн. Үүсгэсэн geometry-г model clone хаагдахад dispose хийнэ; cached эх geometry хэвээр үлдэнэ.
- Standalone GLB болон assembly-ийн хэсэгт texture хэрэглэх урсгалд хоёуланд нь холбосон.
