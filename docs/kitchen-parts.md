# Kitchen Planner — бүрэлдэхүүний бие даасан тохиргоо

Энэ багц нь зуухаас бусад Options panel-ийн дутуу байсан үйлдлүүдийг гүйцээсэн. Төсөлд өмнөх засварууд хэвээр байна.

## Ажиллуулах

Workspace дахь код шинэчлэгдсэн. Өөр хуулбарт суулгахдаа `kitchen-parts-code.zip` доторх файлуудыг төслийн үндсэн хавтас руу бүтцийг нь хадгалан хуулна. ZIP нь өмнөх category/oven багцын хамаарах файлуудыг мөн агуулна.

`kitchen-parts.patch` нь өмнөх `kitchen-components-code.zip` суусан хувилбар дээр хэрэглэх incremental patch:

```powershell
git apply --check patches/kitchen-parts.patch
git apply patches/kitchen-parts.patch
npm run dev
```

ZIP ба patch-ийг давхар хэрэглэхгүй. `http://localhost:3000/kitchen` нээнэ. Шинэ npm dependency, SQL migration, environment variable шаардлагагүй.

## Хийсэн үйлдлүүд

- **Хаалганы навч / Шургуулганы нүүр**: өнгө, материал, хавтгай/хүрээтэй/шилэн загвар тус тусдаа. Шургуулгыг өөрчлөхөд хаалга болон шүүгээний хажуу хавтан дагаж өөрчлөгдөхгүй.
- **Угаалтуур**: ган, керамик, чулуун нийлмэл материал; өнгө; өргөн, гүн, аяганы өндөр. Хэмжээ өөрчлөгдөхөд тавцангийн жинхэнэ нүх болон basin mesh хамт шинэчлэгдэнэ.
- **Холигч цорго**: ган, гуулин, матт металл; өнгө; өндөр болон хошууны урт. Өндөр нь гарнитурын нийт bounds болон Room Planner хэмжилтэд орно.
- **Бариул**: материал, өнгө, урт бариулын урт. Товчин/барилгүй загварт солиход хуучин урт бариулын хэмжээ арилж, бусад тохирох тохиргоо үлдэнэ.
- **Тавцан**: материалыг Settings дотроос шууд сонгоно; нэг шүүгээний өөрчлөлт бусад тавцанд үйлчлэхгүй. Өөр материалтай хэсгүүд салангид тавцан болно.
- **Хөл, суурь**: өнгө, материал болон ухраасан битүү суурь/дөрвөн ил хөлийн загвар. Суурийн өндөр 80 мм хэвээр.
- **Дотоод бүтэц**: бие даасан материал/өнгө, шүүгээний өргөн/өндөр/гүн. Багтахгүй байрлал, хэсгийн хэмжээ, угсрах нүхийг баталгаажуулж алдаа гарвал өмнөх загвар хэвээр үлдэнэ.
- **Солих**: нэрээр хайлт, төрөл/угсрах хэмжээнд тохирох загварууд, ялгаатай SVG preview. Ижил төрлийн угаалтуур солиход тохируулсан хэмжээ, материал, өнгө хадгалагдана.
- **Нийт загварын appearance**: сонгосон scope дахь хаалга/шургуулганы override-уудыг илт шинэчилнэ. Угаалтуур/цорго зэрэг бусад хэсгийн тохиргоонд нөлөөлөхгүй.

## Утас ба компьютер

Утасны 3D/2D зураг эсвэл жагсаалтаас шүүгээ сонгоход **Шүүгээний бүрэлдэхүүн** overview sheet шууд нээгдэнэ. Категори дээр дараад тохиргоо/солих үйлдэл хийнэ. **Бүх бүрэлдэхүүн** товчоор overview руу буцна.

3D toolbar-ийн **Бүрэлдэхүүн хэсгүүд** товч компьютер дээр мөн overview нээнэ. Desktop-ийн inline category list хэвээр. Ангилал солиход detail хэсэг animation-тай өөрчлөгдөж, category navigation-ийн scroll байрлал хадгалагдана. Сонгосон chip харагдах хэсэгт шилжинэ.

Sheet нь Escape, хаах товч, гадна хэсэгт дарах, утасны дээд зурвасыг доош чирэх үйлдлээр хаагдана. Focus болон body scroll буцаж сэргэнэ. Reduced-motion тохиргоог дагана.

## Өгөгдөл ба каталог

`CabinetComponent` нь `type`, `model`, optional `color`, `finish`, `size: {width?, height?, depth?}` агуулна. `getComponents()` cabinet-ийн default-тай нэгтгэж UI/renderer-д өгнө. `parseComponents()` зөвшөөрсөн материал, тухайн хэсэгт тохирох хэмжээ, давхардал болон compatible загварыг шалгана. Үл мэдэгдэх arbitrary pose/GLB URL хадгалдаггүй.

Өмнөх version:1 загвар нээгдэнэ. Өмнөх component override-ууд хадгалагдана. Account save/API болон Room Planner snapshot одоогийн JSON parser-аа ашигладаг тул шинэ тохиргоо хамт дамжина. Frame/tap/sink-ийн хэмжээний өөрчлөлт бодит 3D mesh болон GLB export-д орно.

Энэ төслийн бүтээгдэхүүний каталогт одоогоор бүхэл тавилга байдаг; sink/tap/front/handle-ийн худалдах SKU, угсрах нүхний metadata байхгүй. Иймээс **Солих** нь өөрийн процедур загварын сан. Бодит үнэ, худалдах бүтээгдэхүүнийг зохиож нэмээгүй. Үйлдвэрлэгчийн каталог холбоход product type, хэмжээ, mount/cutout, model implementation, image, unit price шаардлагатай.

Browser дээр desktop/mobile material/size, replacement search, буруу хэмжээ буцаах, reload persistence, overview → detail → back, category scroll, drag close, GLB download шалгасан. Production сайт руу deploy хийгээгүй.
