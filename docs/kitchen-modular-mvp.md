# Модуль гал тогоо — эхний MVP

`/kitchen` дээр **Модуль байрлуулах** горим нэмэгдсэн. Доод, дээд, өндөр шүүгээ тусдаа объект. Өмнөх straight/L гарнитур, өнгө, хаалга, бариулын тохиргоо **Гарнитурын тохиргоо** горимд хэвээр. Горим бүр өөрийн загвартай; горим солиход нээлттэй хуудасны төлөв хадгалагдана. Нуугдсан горимын 3D canvas унтарна. Энэ MVP-ийн modular загвар хуудасны санах ойд хадгалагддаг тул refresh хийхэд шинэ загвараар эхэлнэ.

## Ашиглах

1. **Доод / Дээд / Өндөр** төрөл, **30 / 40 / 60 / 80 см** өргөн сонгоод нэмнэ. Сул ханын зайг автоматаар хайна.
2. **Шүүгээ зөөх** горимд 3D шүүгээг чирнэ. Ханын гадаргуугаас 120 мм-ийн дотор ойртвол ар тал нь хананд наалдаж, урд тал нь өрөө рүү харна. Залгаа шүүгээний хажуугаас 100 мм дотор ирвэл завсрыг 0 болгоно.
3. Улаан хүрээ нь давхцал, өрөө/таазны хязгаар, дээд шүүгээний ханын байрлал эсвэл дутуу босоо зайг заана. Алдаатай байршилд тавихад өмнөх байрлалд буцна. **Esc**, pointer cancel, browser focus алдах нь чирэхийг цуцална.
4. **Харах өнцөг** горимд камерыг эргүүлнэ. Mouse wheel-ээр ойртуулна. Тавцан picking-ийг хаахгүй тул доод шүүгээг сонгож болно.
5. Шүүгээг жагсаалт эсвэл дээрээс харах зургаас сонгоод өндөр, гүн, хаалга/шургуулганы тоог өөрчилнө. **Байрлалыг хэмжээгээр тохируулах** дотор X/Z утга, 90° эргэлт бий. X/Z нь шүүгээний төв хүртэлх хэмжээ. Эдгээр нь mouse drag ашиглахгүйгээр ажиллана.
6. **Өрөөний хэмжээ ба дээд шүүгээний зай** хэсгийг нээж өрөөний өргөн/урт/таазыг өөрчилнө. Одоо байгаа шүүгээнүүд багтахгүй бол өөрчлөлтийг хэрэгжүүлэхгүй, тайлбар харуулна.

## Data model

`src/lib/cabinet.schema.json` — JSON Schema draft-07. `src/lib/kitchenCabinets.ts` — төрөл, default, үүсгэгч, runtime шалгалт.

Бүх хэмжээ **мм**, `rotation` нь **радиан**. `position.x/z` = footprint төв; `position.y` = шүүгээний доод ирмэг; local `+Z` = урд тал. Three.js-д оруулахдаа хэмжээг 1000-д хуваана. State нь serializable өгөгдөл бөгөөд Three.js mesh/material instance агуулахгүй.

```json
{
  "id": "base-1",
  "type": "base",
  "width": 600,
  "height": 820,
  "depth": 600,
  "doorCount": 2,
  "drawerCount": 0,
  "handleStyle": "bar",
  "color": "#b99165",
  "material": "wood",
  "position": { "x": 500, "y": 0, "z": 300, "rotation": 0 },
  "autoElevation": false,
  "fitToCeiling": false
}
```

| Төрөл | Default өндөр / гүн | Байрлал |
|---|---|---|
| Base | 820 / 600 мм | Шалан дээр; 30 мм тавцантай нийлээд 850 мм |
| Wall | 720 / 350 мм | Хананд; доод ирмэгийн өндрийг автоматаар эсвэл гараар тохируулна |
| Tall | Таазны өндөр / 600 мм | Шалан дээр, default нь тааз хүртэл; автомат өндрийг унтрааж болно |

Материал: `matte / wood / gloss`; бариул: `bar / knob / push-open`. Schema, renderer эдгээрийг дэмжинэ. Шинэ modular горимд material/handle сонгох panel энэ шатанд нэмээгүй. 300/400 мм өргөнд нэг хаалга; 600/800 мм-д нэг эсвэл хоёр. Доод/өндөр шүүгээнд 0–4 дээд шургуулга, дээд шүүгээнд шургуулгагүй. Хаалга болон шургуулгыг хоёуланг хадгална; шургуулгууд нь хаалганы дээр байрлана.

`ModularKitchen` нь `version: 1`, `room`, `cabinets`, `wallClearance`, `countertop` тохиргоотой. `Countertop` нь тусдаа объект: `cabinetIds`, `position`, `width`, `depth`, `thickness`, `frontOverhang`, `material`. `fitCountertops()`-оос үүсэх derived объектууд тул cabinet өөрчлөгдөхөд хуучин урт хадгалагдахгүй.

## Байршуулалтын логик

`src/lib/kitchenPlacement.ts` нь browser/Three.js хамааралгүй цэвэр тооцоололтой.

- `snapCabinet()` — finite ханын segment, inward normal ашиглан rotation/байрлалыг олно; ханын үзүүрээс хэтрэхгүй. Өнцөгтэй ханын segment-ээр тесттэй. Одоогийн UI дөрвөн ханатай тэгш өнцөгт өрөө үүсгэдэг; RoomPlanner-ийн багана/олон өнцөгт өрөөг энэ шатанд холбоогүй.
- `footprintsOverlap()` / `cabinetsOverlap()` — rotated rectangle SAT + Y интервал. Ирмэгүүд шүргэлцэхийг зөвшөөрнө; өндөр нь салангид дээд/доод шүүгээ мөргөлдөхгүй.
- `resolveElevations()` — дээд шүүгээний доор давхцах base-уудаас хамгийн өндөр тавцанг олж `top + wallClearance` болгон өргөнө. Доор нь base байхгүй бол 820 мм default base өндөр хэрэглэнэ. Гараар өгсөн өндрийг хадгална.
- `wallCabinetClearance()` — бодит зайг гаргана. Default 550 мм; автомат зайны тохиргоо 450–600 мм. Гараар тохируулсан зай 450 мм-ээс бага бол хориглоно; 600 мм-ээс их бол анхааруулна.
- `fitCountertops()` — залгаа, ижил yaw/өндөр/гүнтэй base-уудын өргөнийг нийлүүлнэ. Завсар, өндөр/гүний өөрчлөлт, эргэлт дээр тусдаа хавтан үүсгэнэ. Tall болон wall дээр тавцан нэмэхгүй. Урд талын илүү гаргалт 20 мм, хажуугийн илүү гаргалт 0 мм. Булангийн тусгай холболт/cut-out одоохондоо үүсгэхгүй.
- `proposeCabinetMove()` — эх төлөвийг өөрчлөхгүй preview ба issues буцаана. Pointer up үед зөв байрлалыг нэг удаа commit хийнэ; React render-ээс өмнө pointer up ирсэн ч хамгийн сүүлийн preview-г ref-ээс авна.

## Хамрах хүрээ, дараагийн шат

Энэ өөрчлөлт **data model + snapping/placement MVP**. Appliance opening/constraint, sink/cooktop cut-out, modular material group panel, U-shape template болон running price дараагийн шатанд орно. Үнэ зохиож оруулаагүй; одоо шүүгээний тоо, тавцангийн бодит хэмжээг харуулна. Шинэ npm dependency, SQL migration, cloud өөрчлөлт байхгүй.

## Шалгалт

16 шинэ тест: schema/type variants, дөрвөн болон өнцөгтэй ханын snap, finite wall endpoint, хоёр талын adjacency, өөр гүнтэй шүүгээний ар талыг тааруулах, эзэлсэн байршил, rotated SAT, босоо давхцал, тааз/өрөөний хил, clearance, countertop split/join, tall, immutable preview, сул зай хайх.

```powershell
node --test tests/kitchen-modular.test.cjs
npm test
npm run typecheck
npm run build
```

Browser дахь pointer/touch үйлдэл, GPU дүрслэлийн шалгалтыг тусад нь хийгээгүй. Дараа нь browser QA хийхэд: 3D чирэх/ханад эргэх, хоёр шүүгээ залгах, давхцалтай газар тавиад буцах, Esc/цонхоос гараад буцах, дээд шүүгээний өндөр ба тааз, устгасны дараах тавцангийн урт, хоёр горимд загвар хадгалагдах урсгалыг шалгана.

Pointer capture болон ray/plane ашигласан API: [React Three Fiber events](https://r3f.docs.pmnd.rs/api/events), [Three.js Ray](https://threejs.org/docs/pages/Ray.html).
