ӨРӨӨ БОЛОН ГАЛ ТОГООНЫ ТӨЛӨВЛӨГЧ — БҮРЭН SOURCE БАГЦ

Энэ багцыг огноогоор шүүгээгүй. Одоогийн src бүхэлдээ болон шаардлагатай public, scripts, config файлууд орсон. Өмнөх IKEA хэв маягийн өрөө төлөвлөгч, 3D удирдлага, өрөө сонгох/хэмжээ оруулах, гарнитур нэмэх самбар болон гал тогооны хамгийн сүүлийн сайжруулалтууд хамт байна.

Ашиглах:
1. Одоогийн төслөө нөөцөлнө.
2. ZIP-ийг тусдаа хавтаст задлаад package.json байгаа үндсэн хавтсыг нээнэ. Эсвэл одоогийн төсөлдөө ижил замтай файлуудыг орлуулна.
3. Өөрийн одоо ашиглаж байгаа .env.local тохиргоог хадгалж/хуулж ашиглана. Нууц тохиргоонууд ZIP-д ороогүй.
4. Node 22.14–22.x ашиглан npm ci, дараа нь npm run dev ажиллуулна.
5. Серверийн заасан порт дээр /planner болон /kitchen?new=1 хуудсыг нээнэ.

node_modules, .next/build cache, .git болон .env нууц файлууд ороогүй. Алсын Supabase, model storage болон төлбөрийн үйлчилгээний өгөгдөл энэ ZIP-д агуулагдахгүй.

Энэ нь шинэ засвар хийсэн багц биш, одоо байгаа файлуудын бүрэн хуулбар. Git-ийн өмнөх commit суурь байхгүй тул файлуудыг 'зөвхөн өөрчлөгдсөн diff' гэж нэрлээгүй.
